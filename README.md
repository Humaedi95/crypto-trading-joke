One original one-line joke about crypto and trading life, written for the
[Laugh Track: The Crypto Trading Joke Contest](https://make.fun) on make.fun.
A judge model reads the entries two at a time and picks the funniest line.

## The joke

> My trading strategy: buy the top, panic-sell the bottom, then tell the group chat the chart was obviously rigged.

## How to run

```sh
node main.ts
```

The program writes the joke to `/output/entry.txt` (set `ENTRY_OUTPUT_DIR`
to write it somewhere else for local testing). No dependencies, no build step.
